# Plancher mémoire P0 — Windows 11 x64 (2026-11-05)

Premier relevé de référence demandé par P0 (`docs/ROADMAP.md`). Il décrit l'application
**au repos** : fenêtre ouverte, aucun document, worker démarré et inactif. Ce n'est ni
un budget ni une mesure de rendu ; il sert de point de comparaison pour les tranches
suivantes, sur la même machine et avec le même protocole.

## Protocole

- Commande : `node scripts/measure-memory.mjs 10 5` après
  `npm --prefix apps/desktop run tauri -- build --no-bundle -- --locked` (depuis bash :
  PowerShell retire le premier `--`).
- Build release du commit `e6b93fd` (`main` après #4), sans installateur.
- 10 lancements successifs ; relevé 5 s après le démarrage ; fermeture normale
  (WM_CLOSE) puis vérification que `pdf-worker` ne survit pas. Cache disque chaud :
  ce ne sont pas des démarrages à froid après redémarrage de l'OS.
- Périmètre : l'arbre de processus du shell (shell, `pdf-worker`, processus WebView2),
  soit 9 processus par lancement.

## Machine

Windows 11 Professionnel 10.0.26300 x64, Intel Core i7-12700KF, 64 GiB de RAM,
runtime WebView2 156.0.4314.58, Rust 1.99.1, Node 24.16.0. Profil d'alimentation et
GPU non consignés.

## Résultats (MiB)

| Mesure | Médiane | Min | Max |
| --- | --- | --- | --- |
| Shell (working set) | 33.2 | 33.1 | 33.4 |
| Worker (working set) | 3.9 | 3.9 | 3.9 |
| WebView2 (working set, 7 processus) | 322.7 | 322.4 | 323.9 |
| Total (working set) | 359.9 | 359.5 | 361.0 |
| Total octets privés | 158.2 | 156.9 | 159.5 |

## Lecture et limites

- La somme des working sets compte plusieurs fois les pages partagées entre processus
  (DLL, mémoire partagée de WebView2) : elle surestime l'empreinte. Les **octets privés**
  (158 MiB) sont l'indicateur à suivre pour les régressions sur Windows.
- La WebView représente l'essentiel du plancher ; le shell Rust et le worker pèsent
  ensemble environ 37 MiB de working set.
- La dispersion sur 10 lancements est faible (< 2 %) ; un p95 n'est pas significatif
  avec cet échantillon.
- Non mesurés : macOS (les services XPC de WebKit ne sont pas des descendants du shell
  et le script ne les compte pas), Linux, mémoire GPU, allocations du heap Rust,
  temps de démarrage.
